Flow3D-DPS 代码与截图方法一致性审查
日期：2026-10-20
代码目录：/u/zguan2/projects/flow3d_runs/flow3d-dps

结论

修正后的实现覆盖截图第2.2节“无条件扩散先验 + 轨迹似然 + DPS”的稳态三维特例。
不能把它描述为一般时变速度场 v(x,t) 的完整实现，也不能把代码测试通过描述为已获得可信的真实后验结果。
正式无条件先验尚未训练；真实GPU训练、GPU采样、超参数校准和重建精度尚未验证。
本次没有提交新训练，没有修改之前36组条件模型训练的代码或任务。

一、逐条对应截图

1. 先训练不输入轨迹的 p(v)：满足。
   dps/training.py 和 dps/data.py 的训练路径只读取训练集速度场及几何，模型条件传入 None。
   归一化只拟合 train；validation 用于去噪损失检查，不参与拟合归一化。
   一个无条件先验不依赖观测粒子数N。旧条件模型权重不能直接作为无条件先验。

2. 给定速度场时不同粒子轨迹独立，联合似然为乘积：满足所采用的残差模型。
   代码计算所有有效粒子和时间区间的残差平方和，NLL = sum ||r||²/(2 sigma²)。
   这等价于乘积高斯因子；省略的是对速度场、深度均为常数的归一化项。
   多视角模式还额外假设相机残差噪声独立，这一扩展需单独声明。

3. 完整三维轨迹公式(2)：满足稳态特例，现已补齐端到端入口。
   FullTrajectoryLikelihood 在观测到的三维位置 x_i(t_j) 插值速度，
   r_i,j = x_i(t_{j+1}) - x_i(t_j) - u(x_i(t_j)) * dt_j。
   --observation-type full3d 明确将 trajectories_3d 作为已观测XYZ轨迹使用。
   该模式不需要二维相机、二维轨迹或隐藏深度；比二维投影提供了更多观测信息。

4. 二维投影轨迹公式及前向算子 U：满足稳态特例。
   ProjectedTrajectoryLikelihood 从观测初始投影和候选深度构造初始XYZ，沿候选场推进，
   r_v,i,j = y_v,i(t_{j+1}) - y_v,i(t_j) - P_v u(x_i(t_j)) * dt_j。
   默认Euler推进；支持不等时间间隔及缺失观测mask。
   --likelihood position 是另一种位置残差模型，不应称为截图中的位移残差公式。

5. 未观测初始深度 P_perp x_i(0)：实现了推断，但包含额外建模选择。
   单视角利用观测射线与已知计算域的交集确定允许深度区间，不读取真实深度。
   默认深度先验为有界均匀分布，采用反射边界的离散Langevin近似更新。
   截图没有指定这一先验或更新算法，不能说它们由截图唯一推导而来。
   满秩多视角由初始投影确定XYZ；不满秩时保留一维深度。
   map/fixed 模式不是对初始深度的后验采样。

6. DPS梯度：满足所采用DPS近似的关键计算路径。
   梯度对带噪状态 x_t 求导，穿过先验去噪网络、反归一化、速度插值及前向粒子推进。
   没有把去噪输出 detach 后只更新干净速度场。加入了断图显式报错。
   支持DDPM和明确标注的DDIM加速变体；不是精确后验采样的证明。

7. 一般时间相关速度场 v(x,t)：尚不满足一般情形。
   当前数据和先验输出为一个稳态三维快照 [1,3,D,H,W]，不是完整时空速度序列。
   多帧输入现明确拒绝，避免误把帧序号当物理时间。
   若后续研究必须覆盖时变场，需要真实时间序列、时空先验及一致的时间插值接口。

二、本次发现并已修复的问题

A. 默认FP16遇到可恢复梯度溢出时会中止训练。
   原因：在GradScaler正常跳步/回退之前，以error_if_nonfinite=True裁剪梯度。
   修复：AMP溢出正常跳过优化并降低缩放，不更新EMA；非AMP非有限梯度仍报错。
   成功优化步数和溢出跳过次数写入checkpoint及记录，并随断点恢复。
   完全没有成功优化步的训练不能被标记完成。
   位置：src/flow_observation/dps/training.py；tests/test_amp_training.py。

B. 采样默认硬覆盖真实边界速度，使用了截图未声明的额外信息。
   修复：--boundary-projection none 成为默认；默认输入路径不读真实边界速度元数据。
   只有显式known模式才启用并记录该额外条件。
   完成生成后可读取边界信息计算统一内部区域指标，不回流到推断。
   回归验证：改变真实运动边界速度，默认生成结果逐值相同；known模式才改变边界。
   位置：dps/data.py、dps/inference.py；tests/test_inference_audit.py。

C. 互相矛盾的初始多视角投影被伪逆静默平均。
   原实现可能在初始位置不满足观测时仍得到零转移残差。
   修复：按尺度相关浮点容差检查初始投影方程，矛盾输入明确报错。
   初始投影作为给定约束；若要支持有噪声且互不一致的初始观测，需另建噪声模型。
   位置：dps/observations.py；tests/test_observation_audit.py。

D. 完整三维公式只有接口，缺少独立CLI和统一回放诊断。
   修复：补齐full3d数据入口、采样分支、probe评估及回放/诊断接口。
   不再依赖任何二维轨迹或相机；三维输入模式与投影模式在元数据中区分。
   位置：dps/data.py、dps/inference.py、dps/observations.py。

E. 完整三维接口曾误接受多帧场但没有正确物理帧时刻。
   修复：明确要求单个稳态体积，避免静默错误；没有声称因此实现了时变场。

F. 输出标签和完成检查不够严格。
   修复：零场引导不再标注为轨迹引导；记录观测协议、稳态范围、边界条件、有效样本数。
   加入--require-valid-replay，可拒绝发布最终越界回放为有效重建。
   检查NPZ元数据与JSON完成记录一致；梯度断图时显式报错。

三、仍需保留的科研限制

- 当前为稳态三维特例，不能直接用于一般时变场。
- 有限域clamp是数值回放近似，不是物理边界条件的完整模型。未观测方向越界时，
  投影NLL仍可能很低；必须同时报告轨迹有效性。没有偷偷删去越界观测或添加新惩罚。
- XY/XZ/YZ三视角把每个分量计入两次；同sigma时NLL不与单视角或完整3D等尺度。
  sigma与引导参数必须按观测协议在validation校准，再固定用于test。
- 默认有界深度先验、Langevin离散步长、DPS引导裁剪会影响后验近似，需要消融与敏感性分析。
- CPU回归测试不是GPU数值稳定性、真实流场精度或后验不确定性校准的证据。
- 现有DiT3D/Tensor-DiT条件模型与DPS需统一数据划分、观测数量、视角、边界信息、
  采样预算和评价流程后才能比较；不得把完整3D观测与二维投影观测混为同一设置。
