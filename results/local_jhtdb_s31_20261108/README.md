# JHTDB 本地基线 · Seed 31

四个模型均完成 100 个 epoch，并于北京时间 2026-11-08 07:52:53 完成留出测试。
数据来自一份冻结的 DNS 快照，按空间区域划分为 2,500 个训练裁块、312 个验证裁块、313 个测试裁块。本实验评估同一快照上的稳态三维流场重建，结论限于该空间留出划分。

输入为单相机视角的 12 条粒子轨迹。所有模型均使用第 100 个 epoch 的 EMA 权重；三个确定性模型每例生成一个流场，UNet diffusion 每例生成两个样本。探针的多视角三角化只用于事后评估。每个模型等权汇总同一批 313 个测试案例，仅包含一个训练种子。
